# ✍️ ویرایشگر متن فارسی آنلاین

ویرایشگری ساده، زیبا و حرفه‌ای برای متن‌های فارسی، با پشتیبانی کامل از راست‌چین (RTL) و طراحی ریسپانسیو با Bootstrap 5.  
امکانات متنوعی برای ویرایش و فرمت‌بندی متن فراهم شده و از پلاگین حرفه‌ای **Pickr** برای انتخاب رنگ استفاده شده است.
